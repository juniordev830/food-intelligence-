# VS Code — food-intelligence-

As tarefas Git, o servidor GitHub MCP e os comandos deste workspace ficam em `.vscode/tasks.json` e `.vscode/mcp.json`.

**Guia compartilhado:** [configurar VS Code, Git e GitHub MCP](https://github.com/juniordev830/codax-assirtende-engenharia-ia-/blob/main/docs/VSCODE_GITHUB_SETUP.md).

Para iniciar e testar **este projeto**, siga o [README local](README.md) e consulte as tarefas em **Ctrl+Shift+P → Tasks: Run Task**.

O fluxo `Git: salvar e enviar` prepara as alterações, cria commit e faz push, sem contornar a revisão, autenticação ou CI. Nunca coloque tokens GitHub no repositório.
